## 一、当前策略结构（P3 在此之上叠加）

每帧 Delivery(100) 与 Economy(110/120) 并行提议，arbiter 同类别放行最高优先级：

- **Delivery(100)**：鲜度最小路径推进 → 站点 PROCESS → RUSH 后 VERIFY_GATE → DELIVER
- **Economy 任务/冰鉴贪心(110)**：NORMAL && 未验核 && raw 任务分 < `TASK_SCORE_GOAL`(90)
  时活跃；估值 = **净值（分值 − 绕路帧×0.12）+ 一步前瞻**；清障任务相邻处理；
  被拒退避（2 次拉黑 50 帧）；固定处理站点让位 PROCESS（`_StationGate` 与 delivery 同源推断）
- **Economy WAIT 蹲守(110)**：无可行候选且 round + 到终点帧 ≤ 600−40 时原地等刷新
- **Economy 冰鉴使用(120，全程)**：停靠且鲜度 ≤ 下个十位阈值+2 即用；上长边前预判跨阈值提前用

关键常量都在 `economy.py` 顶部：`TASK_SCORE_GOAL=90`、`DETOUR_COST_PER_FRAME=0.12`、
`ICE_BOX_MAX_HOLD=2`、`ENDGAME_MARGIN=40`、`TARGET_STICKINESS=2`。
