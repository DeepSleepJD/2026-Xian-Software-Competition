### B1 路线成本模型 —— 前提被数据推翻，暂缓
用强陪练验证后发现"该走山路"前提站不住：
- 强化陪练(山路 raw180 + 2冰鉴 freshness137 + r501 交付 = **737**，忠实对标现网 2696 的 752)。
- **我方当前 Phase A 客户端 vs 此陪练 = 755:737 胜**（seed 20260618/12345 一致），
  靠鲜度 159>137 + 好果 178>169 赢；即"走大路+保鲜"打得过山路对手。
- 理论侧也印证：折算成本(鲜度×1.8 + 帧×0.117)下水路(89.6)恒优于山路(95.8)，
  纯成本模型翻不到山路；唯一能让山路占优的是"任务收成"，但我方大路任务收成已足够。
- 真实败因重判：**任务被对手在我方路线上抢走(争夺)+对手更快+对手用冰鉴**，
  而非我方路线选择。→ 路线成本模型不是这两局的正解，暂缓（避免 774→740 类回归）。

### 同路争夺复现 —— 陪练鲁棒性受限
- 加 `--prefer-route ROAD` 让陪练同走大路直接抢我方任务；但陪练无破卡/复杂障碍
